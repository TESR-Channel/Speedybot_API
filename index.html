Authenticationวิธีเซ็น Alpha-Sign

ทุก request ต้องแนบ header 7 ตัว โดย Alpha-Sign คือ SHA-1 ของ appSecret ต่อกับข้อมูลของ request — appSecret จึงไม่ถูกส่งออกไปเลย ใช้แค่คำนวณลายเซ็น

  1. สุ่ม Nonce + เอาเวลาปัจจุบัน (วินาที)

    Nonce = ตัวอักษรสุ่ม 10 ตัว, Timestamp = Unix time หน่วยวินาที (เวลาเครื่องต้องตรง)

  2. สร้าง fixed string

    alphaAppId={id}&alphaAppKey={key}&alphaNonce={nonce}&timestamp={ts}

  3. GET → เรียง query ตามชื่อ

    k1=v1&k2=v2 แล้วต่อ: appSecret + query + fixed (ไม่มี & คั่น)

  4. POST / PUT → JSON แบบไม่มีช่องว่าง

    appSecret + fixed + JSON.stringify(body) · ถ้าไม่มี body ให้ส่ง {}

  5. SHA-1 → hex ตัวพิมพ์เล็ก

    ได้ 40 ตัวอักษร ใส่ header Alpha-Sign พร้อม Alpha-Robot-Sn, App-Id, App-Key, Nonce, Timestamp, Alpha-language

🔒 ความปลอดภัยของ Key

  • ไม่มี key อยู่ในโค้ดของเว็บนี้ — ทุกคนต้องกรอกของตัวเอง
  • appSecret ไม่ถูกส่งออกไปที่ไหนเลย ใช้คำนวณ SHA-1 ในเบราว์เซอร์เท่านั้น
  • ค่าเก็บใน sessionStorage (ปิดแท็บแล้วหาย) หรือ localStorage ถ้าติ๊ก “จำไว้ในเครื่องนี้”
  • เว็บนี้คุยตรงกับ alpha-pro.csjbot.com เท่านั้น ไม่มีเซิร์ฟเวอร์กลาง
  • โค้ดที่ export จะใช้ environment variables เป็นค่าเริ่มต้น — อย่า commit key ขึ้น Git
  • ถ้า key หลุด ให้แจ้งผู้ผลิต (CSJBot) เพื่อออก appSecret ใหม่
